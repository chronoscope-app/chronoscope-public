Original big-endian float32 values rounded to nearest centimetre; encoding

The original archive README.DATUMGRID identifies this exact grid as:

Worldwide: EGM96 geoid model
Source: NGA
Format: GTX
License: Public Domain
15 minute worldwide geoid undulation grid that transforms WGS84
ellipsoidal heights to physical heights.
File: egm96_15.gtx

Source and checksum were independently verified against the original OSGeo
archive while implementing this adapter. No Cesium ion or remote geoid API
is used at runtime. This display conversion is never written back into the
original DTED records, and generic DTED "MSL" metadata alone is not evidence
that the file uses EGM96. The user must select the known vertical datum.

Reproduce from the repository root:
python3 scripts/build_egm96_grid.py /path/to/egm96_15.gtx

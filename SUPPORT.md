# Support

Read [installation/platform limitations](docs/INSTALLATION.md), [release history](CHANGELOG.md), [user guide](docs/USER-GUIDE.md), [privacy and connections](PRIVACY.md), [CLI/MCP](docs/CLI-MCP.md) and [validation](docs/VALIDATION.md) first. For ordinary bugs or feature requests use the guided [repository issue forms](https://github.com/chronoscope-app/chronoscope-public/issues/new/choose) when accessible. Include version, exact source SHA if built locally, OS/architecture, expected/actual behavior and a small synthetic fixture.

Do not upload real location histories, API keys, certificates, private SI chats or full unreviewed logs. Redact file paths and account names. For security matters follow [private reporting](SECURITY.md), not public issues. This is an experimental project with best-effort support, no SLA, and no implication that all platforms have native acceptance tests.

# Shared navigation without inertia — 2026-10-17

Globe, space-time, 2D Map and Calendar share wheel/right-drag zoom and left/right double-click zoom anchored at the pointer. Middle-drag and Ctrl/Shift-left-drag orbit/tilt 3D views. Shift-wheel tilts, Ctrl/Cmd-wheel rotates and Alt/Option-wheel reduces zoom steps. 2D retains its north-up orientation and ignores tilt/orbit gestures. There is no inertia, automatic zoom-induced tilt or free-look. Tilt gestures are bounded to 0–85 degrees, and navigation cannot move the camera beneath the geographic floor. Navigation does not modify event time, filters or Time height.

Map-focused arrows pan; Shift+arrows rotate/tilt; N faces north; U looks down; F/R fits events; Page Up/Down zooms; Shift+Page Up/Down changes camera altitude in 3D; Alt reduces steps; O switches 2D/Globe. Tables, fields and time-window sliders keep their own keys. Space remains timeline playback. Escape cancels the active pointer gesture before clearing selection. Select mode preserves additive left-drag boxes. Single-click picking captures its exact record immediately and briefly defers delivery to distinguish double-click zoom. Rapid separate clicks flush the preceding pick; double-click retains the previous selection, including when the first click has already been delivered.

The pinned Cesium 1.146 controller still applies a short decay at an inertia coefficient of zero. Its input-loop momentum branch is skipped at one; that cutoff is used for spin/translation/zoom, with real release tests verifying no residual camera movement. No private controller state is changed.

The local integration test uses actual mouse/keyboard input, real GPU picking and the Rust engine. All 13 groups passed across four modes: gesture mappings, fine zoom, cursor anchoring, immediate stopping, selection preservation, rapid additive picking, slow double-click, Escape cancellation, extreme bounds, table ranges, timeline playback and the shared CLI/MCP view adapter. Anchor reprojection error stayed below 0.1 CSS pixel. Tests permit only micrometre-scale position/numerical orientation normalization when checking a stopped camera. The existing CLI zoom-factor range remains intact.

A short Apple M5/Metal browser run retained all 100,000 markers with bloom enabled, exact queries and no render errors or public requests. Callback and rolling-render measurements are recorded separately in [report.json](report.json); this does not claim native 100k FPS or a measured speedup. Windows/Linux native runtime was not exercised here. All verification is local; GitHub workflows remain manual-only.

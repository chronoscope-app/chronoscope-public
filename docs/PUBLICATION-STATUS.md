# Source publication scope and preview status

`chronoscope-app/chronoscope-public` is a new standalone repository prepared from the reviewed current source tree, with one fresh initial commit. It is not a fork. Earlier commit ancestry, pull requests, branches, tags, releases, workflow logs and private audit reports are not included. The original development repository remains private; this preparation does not authorize changing it.

## Included source and limitations

- Chronoscope [0.16.4 experimental preview source](https://github.com/chronoscope-app/chronoscope-public/releases/tag/v0.16.4), current sample datasets, license/NOTICE texts, full maintained GLib vendor source, and the selected 16 README screenshots and their credits. Application names, protocols and commands remain Chronoscope.
- Privacy/connections guidance, guided issue forms, local verification instructions and release/distribution gates. Canonical project links target this repository.
- Current media replacements and provenance are described in [THIRD_PARTY.md](../THIRD_PARTY.md) and the [media ledger](MEDIA-RIGHTS.json). Historical ledger rows describe retired objects, not files or Git objects imported into this repository. Public vessel and wildlife identifiers are credited published data, not a claim of anonymized human tracks.
- The maintained [GLib security backport](../vendor/glib/BACKPORT.md) retains complete source, original licenses and its exact patch record. Version-based alerts may still flag the unchanged upstream crate version; do not dismiss alerts or infer runtime clearance from static checks.
- Older validation documents and changelog entries retain dated measurements and source identifiers as historical context. They are not a claim that old commits, artifacts or private audit evidence can be retrieved here, or that the new snapshot has been natively rebuilt or tested on every platform.

No historical executable, old media composition, copied GSAP runtime, unproven audio or retired terrain payload is imported by this source snapshot. Source publication is distinct from native-package rights/source-access review, signing/notarization and fresh-download acceptance. Follow [distribution](DISTRIBUTION.md), [installation](INSTALLATION.md) and the [release checklist](RELEASE-CHECKLIST.md) before making stronger distribution or acceptance claims. Automated privacy scans are bounded checks, not certification of absence of every secret or private datum.

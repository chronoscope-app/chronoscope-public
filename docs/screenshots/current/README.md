# Chronoscope gallery

Fresh captures of the native Mac app, version **0.15.2**, built locally on 21 October 2026. The app uses WebKit/Cesium and the actual Rust engine. Global views use public-domain Natural Earth II shaded relief; the local gull-density, crime and vessel views use credited Streets mapping. These are app-window snapshots, without composited UI or retouched data. This local development build is ad hoc signed, not notarized, and is separate from the older downloadable previews.

## Reproduce

Build `./script/build_and_run.sh --build-only`, then use `scripts/capture_native_gallery.py` with the resulting app, a fresh absolute profile directory, and `--application-source` set to the full Git commit used for that build. The script uses the app's CLI/agent and native `view capture` command. It loads the credited demos and the checked-in global earthquake and crime projects, and records live rendering status. External map access is disabled except for the credited Streets gull-density, crime and vessel scenes. Density uses a 12-pixel cell-size setting; actual hierarchical grid dimensions depend on zoom. Chart scenes use **Compact chart** to show a small linked card over the map; **Widen chart** restores the editing panel. The linked-workspace capture also uses a real chart-bar selection. After choosing Compact chart and arranging the normal UI, `--scene NAME --current` records the arranged current view. `CHRONOSCOPE_DATA_DIR` isolates a local GUI profile; it must be an absolute path and skips normal-profile migration.
